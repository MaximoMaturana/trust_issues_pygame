# Trust Issues

Trust Issues is a 2D platformer game developed using Python and the Pygame library.
The game focuses on misleading mechanics, traps, and unexpected behavior inspired by
"troll platformer" games.

## Features
- 12 playable levels
- Custom platform types (fake, falling, moving, invisible, conveyor, bounce)
- Multiple spike trap behaviors
- Control inversion zones
- Level restart on player input
- Mirrored mode for extra challenge

## Controls
- Move: A / D or Left / Right Arrow
- Jump: Space / W / Up Arrow
- Restart Level: R
- Exit Level: ESC

## How to Run
1. Make sure Python 3.10+ is installed
2. Install Pygame:

python main.py

.
